# Proprietary blobs for the GPD XD+ (xdplus).
#
# Source: the device's own /vendor partition (mmcblk0p23), an ALLDOCUBE U1005E
# Android 8.1 blob set -- PowerVR DDK 1.9@4893595, ELF "for Android 27".
# None of these are compilable and none ever will be; this tree owns their
# PACKAGING, not their source. build_vendor_image.sh bakes them into vendor.img.
#
# Cross-check: vendor/gpd/xdplus is 318/339 byte-identical to the overlapping
# files in third_party/android_vendor_cube_u1005 (the ALLDOCUBE X tablet, same
# blob lineage). The 21 that differ are genuine XD+ hardware deltas -- MT6630
# combo firmware and its wmt_* / autobt tools, gatekeeper/keystore (TEE-bound),
# sensors, the widevine pair, MTKThermalManager.apk, and libsrv_um.so on both
# ABIs (same 1.9@4893595 build string, different binary). Cube is the ABI
# reference for kernel interfaces; it is NOT the blob source.
#
# Deltas from the untouched stock dump (reversing/vendor_dump), all deliberate:
#   - 108 camera files removed (device has no camera), 0 files added
#   - build.prop                  fingerprint/date/security_patch rewritten to
#                                 GPD/xdplus, release id pinned so it equals
#                                 ro.system.build.fingerprint (isBuildConsistent)
#   - etc/mixer_paths.xml         wired-headset capture routed to the internal mic
#   - lib64/hw/hwcomposer.mt8173.so  acqfd-patched, 31918bb7... -> 54b28199...
#                                 (stock aborts on an unclosed acquire fd)
#
# Ownership, modes, file capabilities and SELinux labels are NOT stored in git
# (which keeps only the exec bit). They live in vendor_fs_config and
# vendor_file_contexts, captured from the partition and applied at bake time.
# vendor_unlabelled.txt lists the 10 paths carrying no security.selinux xattr --
# that is ALLDOCUBE's original state, present in the untouched stock dump too.
#
# Regenerate the metadata from an image with:
#   ./capture_vendor_meta.py <image> proprietary/vendor vendor_fs_config vendor_file_contexts
